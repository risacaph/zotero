# Contributing to Trellis

## Bug Reports and Feature Requests

Trellis does not use GitHub Issues for bug reports, feature requests, or support questions. Please post all such requests to the [Trellis Forums](https://forums.trellis.org), where Trellis developers and many others can help. See [How Trellis Support Works](https://www.trellis.org/support/trellis_support) for more information.

For confirmed bugs or agreed-upon changes, Trellis developers will create new issues in the relevant repositories.
