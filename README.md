Trellis
======
[![CI](https://github.com/trellis/trellis/actions/workflows/ci.yml/badge.svg)](https://github.com/trellis/trellis/actions/workflows/ci.yml)

[Trellis](https://www.trellis.org/) is a free, easy-to-use tool to help you collect, organize, cite, and share your research sources.

Please post feature requests or bug reports to the [Trellis Forums](https://forums.trellis.org/). If you're having trouble with Trellis, see [Getting Help](https://www.trellis.org/support/getting_help).

For more information on how to use this source code, see the [Trellis documentation](https://www.trellis.org/support/dev/source_code).
